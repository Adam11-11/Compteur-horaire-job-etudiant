# Règles du projet — Compteur Paella

## Workflow Git
- Sur ce projet, après chaque série de modifications validées, effectue directement `git add`, `git commit` et `git push origin main` sans attendre de confirmation supplémentaire.
- Si `git` n'est pas dans le `PATH` du shell, utilise `"C:\Program Files\Git\cmd\git.exe"`.
